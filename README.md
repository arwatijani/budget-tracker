# Budget Tracker

A simple command-line expense tracker written in C++.

## Features

- Add expenses with a description, amount and category
- List all expenses with the total

## Technologies

- C++ (STL: vector, string)

## How to run

    g++ main.cpp -o budget
    ./budget

## Example

    1) Add  2) List  3) Quit
    > 1
    Description: coffee
    Amount (EUR): 3.5
    Category: food

## Possible improvements

- Save expenses to a file
- Show totals per category
